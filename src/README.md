# xF No‑Build Frontend

The **xF No‑Build Frontend** is the open‑source, metadata‑interpreted UI shell for the xF deterministic runtime.  
It renders any xF metadata payload into a working HTML/JS application **without bundlers, frameworks, or build pipelines**.

This repository contains:

- The no‑build frontend shell (vanilla JS)
- Standard HTML/CSS/JS control types
- UI templates (forms, grids, dashboards) using Bootstrap 5
- Utility modules for rendering metadata
- Example usage patterns
- Documentation links

The **xF Runtime itself is hosted and proprietary**.  
This repository provides the open‑source client that communicates with the hosted backend.

---

## Features

- **Zero‑build**: no npm, no webpack, no bundlers  
- **Vanilla JavaScript**: runs in any browser  
- **Metadata‑driven UI**: forms, grids, dashboards generated at runtime  
- **Dynamic control loading**: textbox, number, date, boolean, dropdown, grid, blob, custom  
- **Declarative rendering**: HTML templates + metadata → UI  
- **Sandbox compatible**: works with the public xF sandbox database  
- **Self‑hostable**: can run on any static web server
