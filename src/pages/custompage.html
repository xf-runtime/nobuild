xF Custom Pages

Extend runtime capabilities with static templates or reactive entity layouts without any build steps.

Static

Standalone Pages

Documentation, reports, or unauthenticated interfaces independent of entity metadata schemas.

// File placement
templates/pages/about.html
// Accessible Route
#page/about
  • No Server Compilation: HTML loaded as plain assets.
  • Global Helpers: Access $init(), xflush() directly.
Dynamic

Entity Overrides

Replace default auto-generated entity form layout (shell/entity.html) with customized controls.

// File placement
templates/pages/cp_vehicle.html
// Schema setting
Entity Template = "cp_vehicle"
  • Reactive Data: Full scope access to xz.* and xy.*.
  • Standard Actions: Direct wiring to xpost() and refresh().
Routing Quick Links:
#page/landing #entity/uc_vehicle/1
